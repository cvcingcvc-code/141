## 根因

`docs/AUDIT.md:69` 记录了本机 git 身份修复动作，正文写入了作者自身公开邮箱
`cvcingcvc@gmail.com`。该邮箱与仓库所有提交的 author 行
（`cvcingcvc-code <cvcingcvc@gmail.com>`）一致，属**用户自身公开身份邮箱**，
非凭据、非第三方隐私；但按 `V-010` 的「邮箱」模式仍被判定为命中。

## 处置建议（由 A1 / 用户决策，QA 不修改）

- 方案 A：维持现状并显式白名单化——该邮箱已在每个 commit 的 author 元数据中公开，
  正文重复出现不新增暴露面；在 `privacy-scan.mjs` 值级白名单登记
  `cvcingcvc@gmail.com`（仅限该文件该行），并注明理由。
- 方案 B：后续编辑 `docs/AUDIT.md` 时改为占位 `<已登录账号邮箱>`，避免正文再次出现。
- 均不涉及凭据轮换（非密钥/令牌）。
